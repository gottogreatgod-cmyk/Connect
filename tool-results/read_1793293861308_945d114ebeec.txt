  1007→
  1008→## 01 · Global system modules
  1009→
  1010→These appear across nearly every site.
  1011→
  1012→**Architecture**
  1013→
  1014→- Mount these once in the root layout. A header rendered per page breaks focus order and doubles every fetch.
  1015→- Header, footer and consent are singletons: one navigation config, one CTA definition, one legal list — desktop and mobile read the same source so they never drift.
  1016→- Keep interaction state local (open/closed) and lift only what must persist: theme, consent, locale, dismissed announcements.
  1017→
  1018→**Accessibility**
  1019→
  1020→- The skip link is the first focusable element on the page; the header comes after it.
  1021→- Dropdowns and drawers open on focus, close on Escape and outside click, and return focus to the trigger.
  1022→- Every icon-only control needs an aria-label and a focus ring that reaches 3:1 against its surface.
  1023→
  1024→**Performance**
  1025→
  1026→- The header is layout-critical: inline its styles, keep the logo SVG under a few kilobytes, and load the search index only when the overlay opens.
  1027→- Consent, analytics and chat scripts load after interaction — never in the critical path.
  1028→
  1029→**Quality gate**
  1030→
  1031→- Traverse the whole header and footer with a keyboard only, at 200% zoom.
  1032→- Check the sticky bar at 320px width with iOS safe-area insets applied.
  1033→
